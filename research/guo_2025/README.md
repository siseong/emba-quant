# Guo (2025) 미국 시장 재현과 한국 시장 검증 계획

## 최종 목표와 미국 재현의 역할

팀의 목표는 **실적 발표에 정보가 몰리는 달의 시장수익률로 다음 달 한국 시장을 예측하고, 이 신호의 시장 타이밍 전략이 비용과 팩터를 고려한 뒤에도 성과를 내는지** 검증하는 것이다. 분석 단위는 시장 전체의 월간 수익률이다. 미국 재현은 한국에 적용할 코드의 시점 정렬, 신호 산식, 평가 방법을 검증하고 미국 비교 기준을 남긴다. 논문 표 A3의 Fama–French 3요인 및 모멘텀 통제 결과와 수업 프로젝트의 한국 5요인 검정은 각각 보고한다.

논문은 부록 C에서 이미 여러 국가를 묶어 분기 첫 두 달을 뉴스 구간으로 검증했다. 팀의 확장은 한국 단일 시장의 원화 수익률을 사용하고, 미국식 달력과 한국 공시 자료로 정한 달력을 같은 한국 평가 구간에서 비교하는 것이다. [RFS 논문](https://doi.org/10.1093/rfs/hhaf020)

[저자 Stata 코드](https://dataverse.harvard.edu/api/access/datafile/10802971)

이번 범위는 미국 시장 전체의 수익률 예측 및 타이밍이다. 기존 지표 비교(표 A2), 개별 종목과 실적 메커니즘 검증, 글로벌 패널, 그림의 시각적 재생성은 범위 밖이다. 월별 예측과 전략 수익률은 재현 출력에 포함한다.

## 실행

수업의 Python 3.14 가상환경과 `curl`을 사용한다. 검증 환경은 Termux의 Python 3.14.8, pandas 3.0.5, NumPy 2.5.0, SciPy 1.18.1, statsmodels 0.15.0이다.

python research/guo_2025/replicate.py --work-dir ~/emba_quant/guo_2025

빈 디렉터리에서 다운로드부터 계산까지 검증했다. 스크립트는 저자 입력과 기대 출력 5개를 `input/`에 내려받고 SHA-256을 확인한다. `output/comparison.csv`에 실제값·기대값·차이·일치 여부를 기록하고, `output/monthly.csv`에 형성월 기준 예측·신호·실현 수익률·보유월 팩터를 기록한다. 비교값이 하나라도 다르면 종료 상태가 1이다. 공개 원본이나 월별 데이터가 포함된 실행 출력은 작업 디렉터리에 저장한다.

## 한국 실험 데이터 명세

### 1차 요청 범위와 평가 구간

1998-01~2025-12를 요청한다. 최초 월 수익률을 직접 계산할 경우 1997-12 말 지수도 받는다. 기본 시장은 KOSPI이고, KOSDAQ 및 KOSPI+KOSDAQ 통합 시장은 동일한 방식으로 별도 검증한다. 1998~2012년을 초기 훈련과 공시 달력 확정에, 2013~2021년을 미국과 겹치는 주 평가 구간에, 2022~2025년을 추가 평가에 사용한다. 평가 구간은 **보유월**을 기준으로 자른다. 소스에 따라 공통 구간이 짧아지면 수익률을 보기 전에 가용 월과 누락 원인을 문서화하고 모든 비교 모형에 같은 구간을 적용한다.

현재 팀 저장소의 `data/original/dataguide/kospi_kosdaq.xlsx`는 KOSPI·KOSDAQ 일별 종가지수와 이동평균을 담고 있다. 헤더에서 배당 재투자 총수익률과 공시일, 팩터를 확인할 수 없어 현재 파일은 가격수익률 기준의 예비 검증에 사용할 수 있다. 본 검증은 총수익률지수를 추가 확보한 뒤 진행한다. [KRX 시장 데이터](https://data.krx.co.kr/) · [FnGuide 제공 범위](https://help-dataguide.fnguide.com/ko/articles/%EC%A0%9C%EA%B3%B5-%EB%8D%B0%EC%9D%B4%ED%84%B0-%EC%95%88%EB%82%B4-5c5347da)

### 한국 검정 규칙

1. 미국식 1·4·7·10월을 기준 신호로 고정한다. 한국식 후보는 1998~2012년 최초 실적 공개 건의 보통주 시총 가중 합을 달력 분기의 상대 월(첫째·둘째·셋째)별로 집계해 가장 높은 상대 월을 하나 정하고 고정한다. 시총이 없는 공시의 제외 비율과 각 월의 커버리지를 기록한다. 동률이면 앞선 달을 선택한다. 예측할 달이 뉴스월인지는 고정 달력으로 미리 알 수 있다.
2. 직전 네 뉴스월 총수익률을 합산하고, 다음 달이 뉴스월이면 부호를 바꾼다. 월말에 예측을 생성하고 계수는 과거 실현 수익률로만 업데이트한다. 동일한 보유월 표본에서 확장창 평균 대비 OOS R²를 비교한다. 미국은 동일 기간·워밍업으로 재평가하고 별도로 논문의 장기 기준값도 제시한다.
3. 방법 6의 전략은 `예측 수익률 − 과거 평균 수익률`을 보유월 비중의 원형으로 사용한다. 초기 변동성 배율은 훈련 구간에서 추정한다. 원화 시장 수익률로 계산한 논문식 성과와 선물 또는 ETF의 실제 매매 시점·거래비용을 반영한 성과를 각각 기록한다. 실행 검증을 위해 가장 가까운 월물의 거래일별 가격·정산가·만기·롤오버 날짜 또는 ETF의 배당 포함 수익률, 매수·매도 수수료와 스프레드를 별도로 확보한다. 관리 파일은 `execution_daily.csv`로, 키는 `instrument_id,trade_date`이며 열은 `instrument_id,trade_date,open,close,settlement,expiry_date,roll_flag,total_return,half_spread_bps,fee_bps`다. 해당 상품에 적용되는 열을 채운다.
4. CAPM, FF3, FF3+MOM, FF5의 월 알파 및 t값, 표본 수와 월 변동성, 샤프, 회전율을 보고한다. 공급처 다른 자료의 월 시점을 맞추고, 월 누락·중복, 통화·단위 불일치, 공시 가용일 이후 이용 여부를 먼저 확인한다.
